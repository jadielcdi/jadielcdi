### 🌟 Featured Project

#### 🎮 [Project Crossroads](https://github.com/jadielcdi/Project-Crossroads) | *Modular 2D Engine & Visual Novel*
> An event-driven, desktop visual novel framework built using Java, JavaFX, and strict Object-Oriented principles.

* **Architecture:** Uses a **Finite State Machine (FSM)** pattern to handle dynamic branching dialogue trees and game-state persistence.
* **Separation of Concerns:** Strict MVC implementation isolating UI scene transitions from dialogue script parsing and runtime audio binding.
* **Data Flow:** Custom file I/O serialization to load story scripts, trigger character flags, and manage memory-efficient asset recycling.
